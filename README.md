# Class Work Tasks (Java)

This repository contains separate Java files for each task. Each task file is standalone and contains a main method where applicable.

Files:
- Task1.java  -- solves the "closest number not less than average" problem
- Pizza.java  -- Pizza class with fields, getters/setters and toString
- Task2.java  -- demo program for Pizza
- Taxpayer.java -- Taxpayer class with tax calculation
- Task3.java  -- demo program for Taxpayer
- Task4.java  -- counts words and numbers in an input string

Compile all files and run the desired task. Examples:

javac *.java
java Task1
java Task2
java Task3
java Task4
